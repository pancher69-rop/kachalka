# 💪 Тренировочный дневник Влада Цепеша

Современное PWA-приложение для учёта тренировок с автоматическим расчётом КПШ (килограммы × повторения).

## ✨ Возможности

- 📊 **Автоматический расчёт КПШ** по каждому упражнению, блоку, дню и неделе
- 🏋️ **Умный парсер форматов**:
  - `50/15` — вес 50 кг, 15 повторов
  - `1*8,8/8-10` — 1 блин по 8.8 кг с каждой стороны + гриф 10 кг = 27.6 кг, повторы 8-10
  - `110-100/10` — диапазон веса, берётся среднее (105 кг)
  - `1ПМ/1` — предупреждение, если не указано число вместо 1ПМ
- 📱 **Работает офлайн** как PWA (Progressive Web App)
- 💾 **Автосохранение** в localStorage браузера
- 📤 **Экспорт/Импорт** данных в JSON
- 🖨️ **Печать** на одном листе A4
- 📊 **Статистика** по дням недели и упражнениям
- 🎨 **Современный дизайн** с анимациями и градиентами

## 📱 Установка как PWA

### На Android (Chrome):
1. Откройте сайт в Chrome
2. Нажмите меню (⋮) → "Добавить на главный экран"
3. Подтвердите установку
4. Приложение появится как обычное приложение

### На iPhone (Safari):
1. Откройте сайт в Safari
2. Нажмите кнопку "Поделиться" (квадрат со стрелкой)
3. Прокрутите вниз и выберите "На экран «Домой»"
4. Нажмите "Добавить"

### На компьютере (Chrome/Edge):
1. Откройте сайт в браузере
2. Нажмите иконку установки в адресной строке (⊕)
3. Или: Меню → "Установить приложение"

## 📝 Форматы ввода подходов

### Простой формат: `вес/повторы`
```
50/15      → 50 кг × 15 повторов = 750 КПШ
70/10      → 70 кг × 10 повторов = 700 КПШ
```

### Формат с блинами: `N*вес/повторы`
```
1*8,8/10   → (2 × 1 × 8.8 + 10) × 10 = 276 КПШ
2*10/8     → (2 × 2 × 10 + 10) × 8 = 400 КПШ
3*5/12     → (2 × 3 × 5 + 10) × 12 = 480 КПШ
```

### Диапазон веса: `вес1-вес2/повторы`
```
110-100/10 → среднее (110+100)/2 = 105 кг × 10 = 1050 КПШ
```

### Диапазон повторов: `вес/повт1-повт2`
```
50/8-10    → 50 кг × среднее (8+10)/2 = 450 КПШ
```

### Специальные обозначения
```

1ПМ/1      → предупреждение, нужно ввести число вместо 1ПМ
```

## 🔒 Приватность

- Все данные хранятся **локально** в вашем браузере
- Никакие данные **не отправляются** на сервер
- Вы полностью контролируете свои данные
- Используйте экспорт/импорт для резервного копирования

## 🐛 Известные ограничения

- Данные привязаны к конкретному браузеру/устройству
- При очистке кэша браузера данные могут быть удалены
- Рекомендуется регулярно делать экспорт данных
