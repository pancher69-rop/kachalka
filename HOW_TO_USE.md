# 📱 Как использовать приложение

## ✅ Вариант A: Автономный HTML файл (РЕКОМЕНДУЮ)

### Что это?
Один файл `training-diary-standalone.html`, который работает **полностью автономно** без сервера, без WiFi, без интернета.

### Как использовать:

1. **Скачай файл** `training-diary-standalone.html`
2. **Открой двойным кликом** — он запустится в браузере
3. **Работай** — все данные сохраняются в браузере
4. **Копируй куда угодно** — на флешку, в облако, отправь по email

### Преимущества:
- ✅ Работает без интернета
- ✅ Работает без сервера
- ✅ Можно скопировать на любое устройство
- ✅ Можно отправить друзьям по email/мессенджеру
- ✅ Не нужен хостинг
- ✅ Полная приватность — данные только у тебя

### Как поделиться с друзьями:

**Способ 1: Отправить файл**
- Отправь файл `training-diary-standalone.html` по email, WhatsApp, Telegram
- Они просто откроют его в браузере

**Способ 2: Положить в облако**
- Загрузи файл в Google Drive, Dropbox, Яндекс.Диск
- Поделись ссылкой

**Способ 3: На флешку**
- Скопируй файл на USB-флешку
- Передай друзьям

## 🌐 Вариант B: Деплой на бесплатный хостинг (PWA)

### Что это?
Разместить приложение на бесплатном хостинге, чтобы оно было доступно по ссылке `https://твой-сайт.com`

### Преимущества:
- ✅ Доступно по ссылке с любого устройства
- ✅ После первой загрузки работает офлайн (PWA)
- ✅ Можно установить как приложение на телефон
- ✅ Автоматические обновления
- ✅ Красивая ссылка для шеринга

### Недостатки:
- ❌ Нужен интернет для первой загрузки
- ❌ Нужно регистрироваться на хостинге
- ❌ Данные хранятся локально у каждого пользователя

## 🚀 Как задеплоить на GitHub Pages (самый простой способ)

### Шаг 1: Создай аккаунт на GitHub
1. Зайди на https://github.com
2. Зарегистрируйся (бесплатно)

### Шаг 2: Создай репозиторий
1. Нажми "+" → "New repository"
2. Название: `training-diary` (или любое другое)
3. Поставь галочку "Public"
4. Нажми "Create repository"

### Шаг 3: Загрузи файлы
1. На странице репозитория нажми "uploading an existing file"
2. Перетащи файлы:
   - `index.html` (основное приложение)
   - `manifest.json` (PWA манифест)
   - `sw.js` (Service Worker)
   - `icon.svg` (иконка)
3. Нажми "Commit changes"

### Шаг 4: Включи GitHub Pages
1. В репозитории зайди в "Settings"
2. В меню слева выбери "Pages"
3. В разделе "Source" выбери "Deploy from a branch"
4. Выбери ветку "main" и папку "/ (root)"
5. Нажми "Save"

### Шаг 5: Готово!
Через 1-2 минуты приложение будет доступно по адресу:
```
https://твой-username.github.io/training-diary/
```

Эту ссылку можно:
- Отправить друзьям
- Добавить на главный экран телефона
- Открыть с любого устройства

## 🚀 Альтернатива: Netlify (ещё проще)

### Способ 1: Drag & Drop
1. Зайди на https://app.netlify.com/drop
2. Перетащи папку с файлами в браузер
3. Готово! Получишь ссылку вида `https://случайное-имя.netlify.app`

### Способ 2: Через GitHub
1. Зайди на https://app.netlify.com
2. Нажми "Add new site" → "Import an existing project"
3. Выбери GitHub и подключи репозиторий
4. Netlify автоматически задеплоит сайт

## 📱 Как установить как приложение на телефон

### Android (Chrome):
1. Открой сайт в Chrome
2. Нажми меню (⋮) → "Добавить на главный экран"
3. Подтверди установку
4. Приложение появится как обычное

### iPhone (Safari):
1. Открой сайт в Safari
2. Нажми "Поделиться" (квадрат со стрелкой)
3. Прокрути вниз → "На экран «Домой»"
4. Нажми "Добавить"

## 💾 Как сохранить данные

### Экспорт данных:
1. Нажми кнопку "📤 Экспорт"
2. Скачается файл `training_diary_export.json`
3. Сохрани его в надёжном месте

### Импорт данных:
1. Нажми кнопку "📥 Импорт"
2. Выбери файл `.json`
3. Данные восстановятся

### Резервное копирование:
- Регулярно делай экспорт данных
- Сохраняй файл в облаке (Google Drive, Dropbox)
- Отправляй себе на email

## 🔒 Приватность

### Автономный файл:
- ✅ Данные только в твоём браузере
- ✅ Ничего не отправляется в интернет
- ✅ Полная приватность

### Хостинг (GitHub Pages/Netlify):
- ✅ Данные в localStorage браузера
- ✅ Ничего не отправляется на сервер
- ✅ Каждый пользователь видит только свои данные
- ✅ Хостинг видит только факт загрузки страницы

## 🆘 Проблемы и решения

### Данные пропали:
- Очистил кэш браузера? → Импортируй из backup файла
- Сменил браузер? → Импортируй из backup файла
- Сменил устройство? → Импортируй из backup файла

### Приложение не работает:
- Проверь что JavaScript включён в браузере
- Попробуй другой браузер (Chrome, Firefox, Safari)
- Очисти кэш браузера

### Не устанавливается как PWA:
- Убедись что сайт открыт по HTTPS
- Попробуй другой браузер
- На iPhone работает только через Safari
